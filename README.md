# TESO Calc

Планировщик билдов для *The Elder Scrolls Online*: цель (урон, хил, реген, танк), раса, класс, шаблон экипировки, скиллы и распределение 64 очков атрибутов.

```bash
npm install
npm run dev
```

Формулы ориентированы на UESP (динамический скейл Update 33): урон способности ≈ `MaxStat × k₁ + MaxDamage × k₂`. Это прогноз, не парслог.
